# V1 架构与实现规范

状态：V1 目标规范；代码已按本文重构并通过主机离线测试与四种构建，尚未完成实机验收。本文优先于其他设计文档中的目标描述；变更行为必须同步验收用例。

## 产品边界

枪体 ESP32-S3 + ICM-42688-P 输出相对鼠标及 R/1/2/左 Ctrl；独立脚踏输出 WASD。默认脚踏为 STM32F103C8T6，采用独立 PlatformIO 工程和 ST-Link 调试。HID/JTAG 分离仅适用于 ESP32 后端。STM32 分层、接线与移植约束见 [STM32 脚踏指南](STM32_PEDAL.md)。V1 水平握姿、固定 Y/Z 映射，不实现绝对定位、自动压枪、连点、无线或横滚补偿。

默认关闭自动零偏学习和非线性曲线。ADS 仅支持按住，设备端倍率默认 1。以下参数是首轮实现默认值，不是已标定的性能承诺。

## 模块和所有权

上层由可移植 `gg_app` 与 `gg_core` 组成，所有硬件访问通过标准 C `gg_hal_t` 注入。ESP-IDF/FreeRTOS/引脚/IMU 寄存器/TinyUSB 仅存在于 `firmware/platform/esp32`。各固件入口只选择产品并注入 HAL。STM32 SDK/USB 适配放在 firmware/pedal/src/ports，板级配置放在 src/boards，禁止依赖反向进入上层。新增 MCU 或替换硬件时实现适配和目标构建，不修改上层源码；完整接口、时基与生命周期规则见 [HAL 移植指南](HAL_PORTING.md)。下述任务布局是 ESP32 适配实现，新平台可使用外部调度器调用同一个 `gg_app_tick`。

保留一个 1 kHz 应用任务及一个 USB 任务。共享 `gg_usb` 替代 TinyUSB 默认任务（`TINYUSB_NO_DEFAULT_TASK=y`、`TINYUSB_INIT_IN_DEFAULT_TASK=n`），不额外叠加任务。业务状态仅由应用任务修改；USB 提交、连接切换、在途 token 和完成/失败回调仅由 USB 任务修改。应用通过固定容量命令队列提交，回调通过固定容量事件队列返回结果。

| 模块 | 职责 |
|---|---|
| HAL 适配 / icm42688 | 平台驱动、原始输入、传感器归一化、时间与传输 |
| gg_app | 周期编排、去抖/逻辑按键、事件分发、恢复调度、指示与日志策略 |
| calibration | 非阻塞窗口统计，返回候选 bias 或失败原因 |
| aim_engine | bias 扣除、映射、滤波、死区、线性增益、积分余量 |
| gun_controller | 运动状态、交互优先级、提交校准、故障恢复 |
| hid_output | 会话、按键 FIFO、运动积累、提交与完成确认 |
| usb_hid / usb_hid_kbd | 设备描述符及共享传输适配 |
| gg_usb / gg_usb_link | USB 单任务、命令/事件队列、会话及在途 token；物理接口与逻辑接口映射 |
| main / 平台启动器 | 选择产品、绑定 HAL、创建平台任务 |

纯逻辑模块仅依赖标准 C 类型，输入和单调时间由 HAL 注入，不直接访问 GPIO、USB、日志后端或动态内存。去抖、脚踏键码和队列在 firmware/components；板级映射、描述符、硬件配置在 firmware/platform；产品增益和去抖默认值在 gg_app。应用启动检查接口版本、必需回调、参数有效性。

当前代码映射：`aim_engine → gg_aim`、`gun_controller → gg_gun_controller`、`hid_output → gg_hid_output`、`calibration → gg_calibration`，均位于 `firmware/components/gg_core`；设备层文件见两份 DESIGN。下文的模块名指职责，不限定文件名。

## 采样与时间契约

驱动返回 NEW / NO_DATA / IO_ERROR / INVALID；样本包含 gyro_dps[3]、accel_g[3]、uint64 timestamp_us、uint32 sequence、valid。事务成功不能替代有效性检查；检查数据就绪、无效编码及有限值。不得通过数值是否变化判断新样本。

V1 ODR=1 kHz，轮询数据就绪后读完整快照。时间戳是主机观察就绪的时间，不宣称传感器精确采样时间。实现前核对数据手册就绪位及清除语义并记录版本。没有新样本不得推进滤波、校准或积分。

dt 来自连续有效新样本。dt<=0 或 dt>5 ms：丢弃该段运动，清滤波初始化标记和余量，以当前样本重新建立时间基准，下个连续样本才积分。禁止限幅后伪造时间。调度超期后重设唤醒基准，不追赶执行多个伪周期。

周期顺序：连接事件 → 输入扫描 → 控制手势 → 新样本 → 状态/校准 → 运动计算 → HID 输出 → 计时统计。IMU 失败不得阻塞实体按键。

## 状态与交互

USB 状态独立于运动状态；has_bias 单独记录。

| 状态或事件 | 规则 |
|---|---|
| BOOT | 初始化成功进入 CALIBRATING；驱动失败进入 IMU_FAULT |
| CALIBRATING | 禁止运动，非阻塞采样；成功原子提交三轴 bias 并清运动状态；失败保留旧 bias |
| 校准完成 | 成功或有旧 bias 时进入 READY，无 bias 的失败进入 NEEDS_CALIBRATION；RECENTER 仍按住时进入 CLUTCH |
| NEEDS_CALIBRATION | 实体按键可用，禁止运动，等待手动校准 |
| READY 按住 RECENTER | 进入 CLUTCH，立即丢弃未提交运动 |
| CLUTCH | 继续采样但不积分；释放时清滤波、时间基准及余量再返回 READY |
| 连续 20 ms 无有效新样本 | 进入 IMU_FAULT，清运动，按键继续工作 |
| IMU_FAULT | 每 1 s 发起一次非阻塞重初始化，不重复泄漏资源；恢复后重新校准，成功前禁止运动 |

RECENTER 单独长按仍只执行 clutch。RECENTER+PROFILE 同时按满 1 s 触发一次窗口校准，两键都释放后才重新允许触发。PROFILE 单键短按在释放时切档；两键发生重叠即消费本次 PROFILE，不能误切档。校准中忽略重复请求，释放 RECENTER 不取消校准。

扳机、ADS、R/1/2/Ctrl 在所有运行状态按实体状态输出；PROFILE/RECENTER 不输出主机键。

## 校准及算法

窗口 2 s，至少 1800 个有效新样本，最大样本间隔 5 ms；不满足则失败，不无限延长。每轴均值绝对值<=3 dps、标准差<=0.3 dps；加速度模长均值 0.9..1.1 g、标准差<=0.02 g。使用稳定在线统计，失败有明确原因。开机只尝试一次，失败等待手动校准，不用零 bias 继续运动。

这些检查不能证明绝对静止，微小匀速转动仍可能被误识别，用户必须静置设备。禁止用单样本替换 bias，禁止背景自动学习。

运动链：扣 bias → 固定映射 → 按实际 dt 计算的 55 Hz 一阶低通 → 软死区 → 线性增益 → counts_per_degree × dt → 向零截断并保留有符号小数余量。

默认死区 0（配置范围 0..1 dps），counts_per_degree=3，三档 gain=0.6/1.0/1.2，启动第一档，ADS 倍率=1。首次样本仅初始化不输出。clutch、校准提交、断线/恢复、故障、异常 dt 均清滤波历史、余量和未发送运动。不得扩大死区掩盖校准问题。

## HID 传输契约

传输提交成功表示报告已复制进 USB 命令队列并交出所有权，不表示主机收到。USB 任务检查会话、端点可用及在途占用；不能发送时返回该报告原始 session/submit_id 的 FAILED 事件。完成事件也使用提交时保存的 token，不读取当前会话拼装。脚踏物理接口 0 映射为核心逻辑键盘接口 1。已交给传输层的报告与已提交 USB 的报告一样不承诺撤回；clutch 丢弃核心尚未提交的积压运动。

挂起不等于端点重置，因此保留旧在途 token，完成后仍携带旧会话，不能误确认新报告；旧在途超过 100 ms 则请求重连。软件断开显式产生 DISCONNECT，不依赖 TinyUSB 必然回调 umount。事件溢出计数使用原子读写，应用检测变化后触发重连恢复。

每接口维护 32 项完整按键快照 FIFO。去抖状态改变才入队，同一扫描内的变化合并。禁止覆盖未发送的 press/release。脚踏 W+S、A+D 均同时输出，由游戏解释。

每接口最多一个在途报告。发送成功仅代表提交，成功完成事件才移除队头；提交拒绝或失败完成保留按键队头重试。事件带会话代号和提交标识，忽略旧会话事件。回调通知溢出也必须进入状态恢复流程，不能无声丢失完成通知。

鼠标优先以零位移发送按键队头，否则发送当前按钮和运动。运动宽整数积累，每轴上限 ±256，超限丢弃并计数，拆包 ±127。未提交运动最多保留 20 ms，超时整体丢弃。运动提交成功即扣除，在途失败丢弃该份运动并计数，不能重复发送位移。

队列溢出：记录错误，清未提交队列和运动，等待在途完成后先发全释放，再发最新实体快照；恢复期间变化合并到最新快照。此时允许丢短按，但必须恢复一致状态。若在途 100 ms 未完成，结束会话并请求 USB 层恢复，不永久等待；恢复前禁止提交新报告。

断线/挂起立即结束会话、清队列和运动，只跟踪实体状态。重连/恢复先全释放再同步最新快照，不重播离线动作；运动重新建立样本基准。使用连接事件，不仅轮询 mounted 布尔值。已提交 USB 的报告不能承诺撤回。

## 可观测性和验证

每 5 s 汇总状态、校准失败原因、有效/无效样本、IO 错误、最大样本间隔、调度超期、队列高水位/溢出、丢运动、完成报告数和重连数。执行耗时与采样间隔分开。热路径和回调不逐样本打印。

LED 优先级：FAULT 每 100 ms 翻转，NEEDS_CALIBRATION 250 ms，CALIBRATING 500 ms；其他状态未连接 1 s 翻转，连接常亮。按单调时间驱动。

必须执行纯逻辑离线测试以及枪体/脚踏 × HID/JTAG 四种构建。固定实际验证的 IDF 版本并提交依赖锁文件。无工具链或硬件时记录未执行，不能宣称通过。详细实施顺序见 IMPLEMENTATION_PLAN.md。
